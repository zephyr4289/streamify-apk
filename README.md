# Streamify 🎧

An ultra-high-performance, bare-metal C++ self-hosted Spotify platform and web player engineered specifically for highly constrained hardware (like an Intel Pentium dual-core personal NAS with 4–8 GB RAM and an HDD).

Streamify delivers a pixel-perfect, hyper-responsive Spotify Web UI powered by direct HTTP Range audio streaming (0% server-side CPU decoding overhead), multi-user profile isolation with 4-digit PIN authentication, and an embedded AVX2 SIMD artificial intelligence recommendation engine ([`music-procengine`](file:///data/data/com.termux/files/home/streamify/music-procengine)).

---

## 🚀 Key Features

* **⚡ Bare-Metal C++ Architecture**: Powered by the **Drogon** C++ async HTTP framework and thread-local **SQLite3** in WAL mode for lock-free database operations with under 10 MB RAM consumption.
* **🔐 Multi-User Profile & PIN Security**:
  * **Automatic Registration & PIN Login**: Enter a profile name (*e.g., Alex, Sarah, Living Room*) and set a 4-digit PIN for instant profile creation and access verification.
  * **Persistent Session Memory**: Session tokens saved in browser `localStorage` and verified via `Bearer` token headers for seamless login without re-typing credentials.
  * **100% Isolated Tastes**: Per-user liked songs (`user_liked_songs`), custom playlists, and isolated Markov chain play/skip behavior models so user recommendations never mix.
* **📥 On-Demand Music Downloader (`dload-engine`)**:
  * **Automated Online Search & Acquisition**: When a song is missing from your local NAS, clicking **"Download to NAS"** triggers an async background downloader powered by `yt-dlp` and `ffmpeg`.
  * **Automatic Metadata & AI Vector Ingestion**: Downloads high-quality MP3 audio, extracts ID3 tags and cover art, registers the track in `streamify.db`, and triggers `music-procengine` for AI embedding generation and instant playback.
* **🎵 Zero-CPU Audio Streaming**: Serves raw audio (`.mp3`, `.flac`, `.wav`) using `206 Partial Content` (HTTP Byte-Range Requests) with small 64 KB kernel disk buffer pipes. Client browsers natively decode audio via client-side hardware acceleration, maintaining **0% NAS CPU overhead**.
* **🧠 Embedded Intelligence Submodule ([`music-procengine`](file:///data/data/com.termux/files/home/streamify/music-procengine))**:
  * **Multi-Chunk Audio Sampling**: Decodes audio slices at 25%, 50%, and 75% of track duration into 64-bin Log-Mel Spectrograms via FFTW3 STFT.
  * **512-D ONNX Neural Embeddings**: Runs INT8 quantized LAION CLAP (`laion/clap-htsat-fused`) for native C++ feature extraction.
  * **AVX2 SIMD Vector Search**: Computes exact cosine similarity in sub-milliseconds using `_mm256_dp_ps` intrinsic loops.
  * **Two-Stage Multi-Factor Ranking**: Ranks candidates using Session Vectors (exponential decay: 70% current, 20% prev 1, 10% prev 2), Markov chain play transition probabilities, BPM rhythmic flow penalty, and negative feedback skip penalties per user.
* **🎨 Authentic Spotify Web Player**:
  * **Pixel-Perfect Spotify Aesthetics**: Built with an authentic Spotify palette (`#121212` background, `#181818` card containers, `#1DB954` green accents, Montserrat/Poppins typography).
  * **Full-Featured Sticky Player Bar**: Album art cover, draggable seekbar with timestamp labels, volume control + mute toggle, play/pause, next/previous, shuffle, and interactive heart toggle for liked songs.
  * **Up Next Queue Drawer**: Dynamic slide-out queue displaying real-time upcoming tracks generated by the recommendation engine.
  * **Automated Event Tracking**: Real-time logging of play and skip events per user profile.

## 🛠️ Build & Installation Instructions

### Prerequisites
* `CMake` (3.15+)
* `GCC/Clang` (C++17 support)
* `Drogon` (`libdrogon-dev`)
* `SQLite3` (`libsqlite3-dev`)
* `JsonCpp` (`libjsoncpp-dev`)
* `FFTW3`
* `ONNX Runtime`
* `Python 3` (for DB setup and ONNX exporter scripts)

### Setup & Compilation

```bash
# Clone the repository with submodules
git clone --recursive git@github.com:sireenyadav/streamify.git
cd streamify

# 1. Initialize SQLite databases
make init-db

# 2. Build C++ binaries
make build

# 3. Launch Streamify Server (listening on http://0.0.0.0:8888)
make run-streamify
```

## 📡 API Reference

### Multi-User Authentication & Profile API
* `POST /api/v1/auth/login`
  * Body: `{"username": "Alex", "pin": "1234"}`
  * Response: `{"status": "success", "token": "...", "user": {"id": 1, "username": "Alex"}}`
* `GET /api/v1/auth/me`
  * Headers: `Authorization: Bearer <token>`
  * Response: `{"user": {"id": 1, "username": "Alex"}}`
* `POST /api/v1/auth/logout`
  * Headers: `Authorization: Bearer <token>`
* `GET /api/v1/user/liked`
  * Headers: `Authorization: Bearer <token>`
  * Returns JSON list of tracks saved by the authenticated user.
* `POST /api/v1/user/liked/toggle`
  * Headers: `Authorization: Bearer <token>`
  * Body: `{"track_id": 5}`
  * Response: `{"track_id": 5, "is_liked": true}`

### Audio Streaming
* `GET /api/v1/stream?id={track_id}`
  * **Headers**: `Range: bytes=start-end`
  * **Response**: `206 Partial Content` (Audio Byte Slice) with `Accept-Ranges: bytes`

### Catalog & Search
* `GET /api/v1/tracks`
  * Returns JSON list of all available tracks.
* `GET /api/v1/tracks/search?q={query}`
  * Returns filtered JSON array matching track title or artist.

### On-Demand Downloader (`dload-engine`)
* `POST /api/v1/download`
  * Headers: `Authorization: Bearer <token>`
  * Body: `{"query": "artist or track name"}`
  * Response: `{"status": "success", "track": {"id": 12, "title": "...", "artist": "...", "duration_sec": 210, "filepath": "..."}}`

### AI Recommendations & Behavioral Tracking
* `GET /api/v1/recommend/next?current_track_id={id}&recent_history={id1,id2}&user_id={user_id}&limit=5`
  * Returns top recommendations calculated by Two-Stage Session Vector & AVX2 Cosine engine for the user profile.
* `POST /api/v1/event/play`
  * Body: `{"current_track_id": int, "previous_track_id": int, "user_id": int}`
* `POST /api/v1/event/skip`
  * Body: `{"current_track_id": int, "previous_track_id": int, "user_id": int}`
